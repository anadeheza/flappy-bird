# Flappy Superman

A Flappy Bird-style game with a Superman style, made using Godot.

## How to Play

Fly through the pipes as Superman by pressing "Space" (or tap/click) to fly, the game is super straightforward, touch a pipe, you die, touch the ground, you die

Every pipe you go through is a point for you, get to see how far you can go :)

## Where to play
No need to download anything, you can play online on both computer and phone via itch.io: https://anadeheza.itch.io/flappy-superman  

## How to Run it Locally
1. Clone or this repository.
2. Open the project in Godot.
3. Press F5 to run.

I did not make a .exe for this project, may do later on
